# Brand — Session Handshake

A small, deliberate identity: **deep terracotta + warm black**. Confident, warm, developer-native.

## Logo

The mark is **two interlocking chevron-brackets** — two sessions meeting and linking, the handoff made visual. It reads clean at favicon size and in a single colour.

| File | Use |
|---|---|
| `assets/logo.svg` | Primary mark, for **light** backgrounds (terracotta + ink) |
| `assets/logo-dark.svg` | Mark for **dark** backgrounds (terracotta + cream) |
| `assets/icon.svg` | App-icon / avatar tile (mark on terracotta) — use for the GitHub org/repo avatar |

**Do:** keep clear space around the mark (≈ half its height); use the light/dark variant that fits the background; scale it freely (it's vector).
**Don't:** recolour it outside the palette, add effects/shadows, stretch it, or place the ink variant on a dark background (it disappears).

## Palette

| Token | Hex | Use |
|---|---|---|
| Terracotta (primary) | `#B5451F` | Mark, headings accent, links, buttons |
| Terracotta bright | `#D2691E` | Highlights, gradients, hover |
| Ink (warm black) | `#1B1310` | Text, dark backgrounds |
| Cream (paper) | `#F7F2EC` | Light backgrounds, text on dark |
| Warm gray | `#B7A79B` | Secondary text, captions |

## Type

**Poppins** (600/700 for the wordmark and headings, 300 for taglines). System fallback: `system-ui, Segoe UI, Arial, sans-serif`. Body copy can use the platform default.

## Social preview

`banner.png` (1280×640) is the Open Graph image. Upload it at **GitHub → repo Settings → Social preview** so shared links unfurl with the brand.
